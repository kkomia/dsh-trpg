## 已实现机制

- **存档**：每次房间事件触发 debounce（800ms）快照到 `$DSH_HOME/profile-data/<profile>/dsh-trpg-table/rooms/<roomId>.json`；tmp→rename 原子写；关闭时强制 flush。
- **续团**：插件启动先恢复房间（含玩家 token，客户端 localStorage 里的 token 重连即可继续），再拉起 HTTP 服务；AI 模式房间重新创建 GM 会话，GM「最近事件」从存档事件继续。
- **真人 GM**：GM 指令只接受 host token；场景与奖励均为服务端投影（奖励只到目标玩家，GM 可见）；旁白走与 AI 相同的 narration 通道。
- **双 GM 模式**：human 模式不启动 Agent（已有单测）；AI 模式可随时用 GM 控制台人工干预。
