## 与设计文档的偏差（已确认合理）

- 规则数据用 **TypeScript 数据模块**（`rules/*.ts`，强类型、零解析成本）；角色卡 / 世界书 / 模组仍用 **JSON**（内容作者可直接编辑、可被导入器读取）。DESIGN §5.3 的「全部 JSON」在 M1 收敛为这个组合，M5 再补 JSON 导出/导入适配器。
- 距离用单一遭遇档位（接触/近/远）+ 武器射程判定，不做逐人坐标；符合设计文档 theater-of-mind 约定。
- 反应（reaction）与复杂持续法术未实现（v2）。
