# M6 验收报告 — 对话原生牌桌

日期：2026-11-16
状态：**本机实机验收通过**（本机 DSH 桌面应用）；局域网双机（host + 另 1–3 台真机）验收待执行

## 目标

主理人反馈：不要自绘聊天界面，直接复用 DSH 的 AI 对话框架；控件放对话头部 + 右侧栏常驻卡片。

即「会话原生牌桌」：房主当前打开的 DSH 会话就是牌桌，AI GM 就是这个会话的 Agent；玩家行动以用户消息注入会话，GM 的原生回复与工具卡由 DSH 原生渲染；插件只保留对话头部入口、右侧栏「跑团桌」tab（常驻紧凑卡片）与建房/加入最小表单。

## 设计要点

- **会话原生牌桌**：不接管主区域、不自绘聊天气泡流、不提供插件输入框；AI 的 markdown 回复、流式输出与 `trpg_*` 工具卡片全部走 DSH 原生渲染。
- **房间 ↔ live 会话绑定**：`room.create` 可带 `sessionId`（建房即绑定），`room.bind`（host token）绑定/改绑/解绑；`RoomView.sessionId` 与房间存档携带绑定；关闭房间 `onRoomClosed → tableBridge.unbind` 自动解绑并撤销注入。
- **`trpg_*` 工具**：GM 工具统一加 `trpg_` 前缀，避开 subagent 全局工具同名遮蔽；工具与 GM 系统提示段只注册在牌桌会话的 Agent 作用域（`TableSessionBridge`），系统提示同步实际工具名。
- **`user/message` 注入会话**：玩家行动 → `sessionController.prompt` 以队列方式送进会话 inbox（`【角色名】…` 前缀，悄悄话带「（悄悄话给 GM）」标记），行动者由服务端绑定；会话 Agent 直接回复。
- **assistant 回写房间**：`ctx.on('session/event')` 的 `assistant/message` → `roomService.gmNarrate` 广播为 GM 旁白（玩家侧/战报用）；`turn/end` 异常 → `gmAlert`。
- **右侧栏 tab + 常驻卡片**：`sidebarRightTabs.register({ id: 'dsh-trpg-table:table', kind: 'trpg-table', title: '跑团桌' })` + `sidebar.right.pane.tab` 正文；对话头部「🎲 跑团桌」按钮 → `sidebarRight.openTab('trpg-table')`，顺带把当前 `sessionId` 写进 localStorage 兜底。无房间 = 大厅（房主地址 / 开团 · 我是房主 / 加入朋友的团）；进房 = 房间状态、玩家席、落座、掷骰、GM 控制台、成长。
- **无插件输入框**：v2 的主区域整页面板、feed 气泡流、`main` / dock / composer 输入框全部删除（`conversation.composer.dock` 不再占用）。
- **清理**：`debug.*`（sessions/create/gateway/fetch/tail/prompt）、`probeCapture`、`probeAgentErrors`、`debugHandlerRef`、`DSH_TRPG_DEBUG_DIR`、`gm-bare` 全部移除。

## 验收中发现并修复的 bug：房主「结束房间」不关房

- **现象**：房主点「结束房间」原来只断开本地连接、不发 RPC；服务端房间与「绑定本会话」继续存活，导致 GM 系统提示与 `trpg_*` 工具持续注入会话。
- **修复**：`packages/dsh-trpg-table/src/client/index.ts` 的 leave 回调按角色分流——房主走 `room.close`，玩家仍走 `room.leave`。
- **复验**：重新构建 + 重载 DSH → 建房 → `room.list` 可见 1 间 → 点「结束房间」→ `room.list` 立即为空、UI 回大厅；`onRoomClosed → tableBridge.unbind` 撤销注入。

## 已知限制

- **旧 token 残留**：重载后 localStorage 里残留旧房 token 会红字提示「无法恢复房间：令牌无效或已失效」，应改为静默清理（尚未做）。
- **重开 tab**：页签已打开时再点对话头部「🎲 跑团桌」会重开页签（短暂空白 + 右栏宽度回默认），不产生重复页签；待做幂等打开。
- **玩家退出不关房**：玩家「退出房间」只离席，房间与牌桌绑定继续存在（设计如此；房主「结束房间」才关房解绑）。
- **极窄栏宽**：≈300 CSS px 且多页签时页签标题会被截断（卡片本身正常）。
- **远端玩家行动入口**：v3 删除插件输入框后，玩家行动尚无 UI 入口（`room.say` 目前由探针/回归脚本调用），随 M7 玩家镜像一并接上。
- **live 会话约束**：只有被 DSH 页面驱动（live）的会话能完成模型请求；插件新建/恢复的会话一律 `TRANSPORT` 失败，未打开的会话 `room.bind` 返回可读错误。
