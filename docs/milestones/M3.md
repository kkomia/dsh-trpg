E2E 覆盖（真实 HTTP+SSE，假 Agent 代替模型）：
- AI 模式建房 → GM 会话创建 → 6 个工具注册到该 Agent 专属作用域 + 系统提示注入
- 自动开场回合（`【开场】`）→ 叙事广播到房间 SSE
- 玩家加入/落座/提交行动 → 行动 prompt 含「行动者」绑定与「只有这一位玩家行动」，另一个玩家不会被标成行动者
- 假 Agent 调 `roll_check` → 引擎掷骰 → 房间收到带 DC/成败的 dice 事件
- 假 Agent 的 assistant 消息 → 广播为公共叙事事件

反串角保障（机制层，测试覆盖）：
- 行动者由服务端 token→playerId→角色注入 prompt，客户端无法自称他人
- 检定/掷骰只能通过工具走引擎；prompt 明文禁止自算骰子
- 私密信息只能通过 `secret_note`（只发给该玩家，GM 可见）
- GM 工具注册在 Agent 专属作用域（`agentCtx.tools`），不会污染其他会话
