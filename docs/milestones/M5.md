## 使用方法

```bash
pnpm install && pnpm build      # 构建 lib
pnpm pack:plugin                # 生成 dist/dsh-trpg-table-<version>.tgz
```

朋友安装：DSH → 插件 → 添加插件（选择本地 tgz），或在 shell 里 `dsh plugin add <tgz 路径>`。
