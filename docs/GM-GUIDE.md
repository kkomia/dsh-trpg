# GM / 房主手册（跑团桌 · TRPG Table）

> 你是房主：房间、存档、AI GM 都跑在你这台电脑上。玩家只需要安装插件并连到你的局域网地址。

> **UI v3（2026-11-16）**：跑团桌不自绘聊天页——房主当前打开的 DSH 会话就是牌桌，入口在对话头部「🎲 跑团桌」按钮 / 右侧栏「跑团桌」tab（常驻卡片）；DSH 停在「新会话」空态页时，左上角也有「🎲 跑团桌」入口（点它会先准备一个会话再打开右侧栏）。**本机单机链路已实机验收通过（2026-11-16）**；**局域网双机验收待用户执行**（见 `docs/ACCEPTANCE.md` §2）。本手册已按 v3 更新。

> **内容包 / 工坊（M8.2 + M9.6）**：建房前在大厅「内容包 / 模组」卡选择本次要跑的内容，默认内置包 `core-guimuya` + 模组「鬼木崖·异光」；房间卡显示所选内容包/模组/版本，GM 控制台场景下拉来自所选模组。数据目录里的 `.trpgpack` 见 §6；本机内容工坊可编辑/导入导出内容包（§6.1，仅房主本机可用）。

## 1. 建房

1. 在 DSH 里打开一个会话（它将成为牌桌会话）。**只有正在 DSH 里打开、被页面驱动的会话才能让 AI 回话**；插件新建/恢复的会话会 transport 失败；
2. 点「🎲 跑团桌」：正常对话页在对话头部；如果 DSH 停在「新会话」空态页（没有对话头部），点该页**左上角**的「🎲 跑团桌」——它会先请 DSH 新建一个会话，再打开右侧栏「跑团桌」tab（之后在会话里说开场，AI 才会回话）；
3. 「开团 · 我是房主」：先在「内容包 / 模组」卡选择本次要跑的内容——默认内置包 `core-guimuya` + 模组「鬼木崖·异光」（只有一个包/模组时显示为只读行，多个包/模组会变成下拉框；若显示「目录不可用」则静默用内置包，不影响建房）；填团名（默认随所选模组标题联动，手改后不再覆盖）、选 **AI 当 GM** 或 **真人 GM** → **创建房间**（会把当前会话绑定为牌桌）；之后也可在房间卡片点「绑定当前会话 / 改绑到本会话」；
4. 房间卡会显示「内容包：… / 模组：… / v版本」；若出现红字「⚠ 内容包缺失或已变更，GM 回退到内置模组」，说明房间引用的内容在本机不可用，先按 §6 处理，不影响继续带团；
5. 记下 **6 位邀请码**（只有房主能看到），把「你的局域网地址 + 邀请码」发给朋友；
6. 确认你的局域网 IP：`ipconfig` 里 IPv4 地址，房间服务默认监听 `0.0.0.0:45871`。

> 朋友连不上：Windows 防火墙首次会弹窗，选「允许专用网络」；或手动放行 TCP 45871。

## 2. 两种模式

| | AI 当 GM | 真人 GM |
|---|---|---|
| 谁叙事 | AI（牌桌会话的 Agent，用宿主配置的模型） | 你（GM 控制台写旁白，或在会话里直接说） |
| 数值/掷骰 | 引擎结算，AI 调用 `trpg_*` 工具请求 | 引擎结算，你用掷骰/工具 |
| 开局 | 绑定会话后 AI GM 就在这个会话里；在会话里说一句开场（如「开始」）即可 | 你手动发第一段旁白 |
| 干预 | 你随时可用 GM 控制台接管 | — |

**建议**：第一次带团用 AI 模式，你同时当玩家也能玩；熟悉后再试真人 GM。

## 3. GM 控制台（房主专属）

右侧栏「跑团桌」tab 的房间卡片里点「GM 控制台」（仅房主可见，可折叠）：

- **发送旁白**：以 GM 身份向全桌描述（走与 AI 相同的叙事通道）；
- **私发**：选玩家 → 填内容 → 只有该玩家（和你）能看到；
- **推进场景**：从所选模组的场景下拉里选一幕（场景清单来自 `room.scenes`，即当前房间内容包的模组）→ 全桌收到「📍场景推进」并更新房间场景标记；
- **发奖励**：选玩家 + XP + 物品（逗号分隔）→ 只有该玩家收到奖励卡（GM 可见）。

其他管理：玩家席每行「移除」（踢人）；房间卡片「锁房/解锁」；房间卡片「结束房间」（房主）= 真正关房并解绑牌桌会话（GM 提示与 `trpg_*` 工具不再注入）；玩家点「退出房间」只离席，不关房。

## 4. AI GM 的工作方式（为什么它不会串角）

- AI GM 就是**牌桌会话的 Agent**：插件在会话上注册 GM 系统提示段（人格/模组/硬规则）与 `trpg_*` 工具；模组与世界书按本房间引用的内容包解析（缺省内置包）；GM 的回复是会话里的原生消息，工具卡由 DSH 原生渲染；
- 每个玩家行动由服务端绑定身份后以用户消息注入会话，prompt 里明确「本次只有这一位玩家行动」；
- AI 想掷骰/检定必须调用工具，骰面与成败由引擎算出，AI 不能自己编数字；
- AI 只能通过 `trpg_secret_note` 私发信息；世界书里的 GM 秘密不会直接说破；
- 战斗里 AI 只能让「当前行动者」攻击，抢回合会被引擎拒绝。

## 5. 存档与续团

- 房间状态自动存档到：
  `C:\Users\<你>\.dsh\profile-data\desktop\dsh-trpg-table\rooms\<roomId>.json`
  （每次事件后 800ms 内落盘，原子写）；
- **DSH 重启后自动恢复房间**：你和玩家刷新页面/重开 DSH，用原来的地址+令牌重连即可续团；
- **内容引用随存档保留**：存档记录房间引用的内容包/模组/版本/内容指纹；续团时若本机缺包或内容变了，房间按内置内容降级续团并在房间卡红字告警（存档不丢，补包重扫后恢复原内容，见 §6）；
- **牌桌会话需重新打开**：房间恢复后，只有你重新在 DSH 里打开该会话（live）才能让 AI 继续回话；右栏卡片可查看/改绑牌桌会话；
- **结束房间 = 关房并解绑**：房主点「结束房间」后房间从存档移除（重启不会恢复），会话上的 GM 提示与 `trpg_*` 工具撤销；玩家「退出房间」只离席，不关房；
- 手工备份：复制上述目录即可；删除对应 json 再重启 = 丢弃该房间。

## 6. 内容包、模组与自制内容（M8.2）

- **默认内容**：内置包 `core-guimuya`，含模组「鬼木崖·异光」（3 幕：接悬赏 → 查古洞 → 守关战，45 分钟左右）、预制角色卡 4 张、世界书 10 条（含 3 条 GM 秘密）、怪物 12 种。零配置可用，不需要装任何文件；
- **建房选内容**：大厅「内容包 / 模组」卡里选（默认即内置包）；房间只记录 `{packId, moduleId}` 引用，内容始终由房主本机的 pack registry 解析，玩家端只拿脱敏目录、不拿 GM 内容；
- **安装自制/第三方包**：把 `<packId>-<version>.trpgpack`（建议先用 `node scripts/content-pack.mjs validate <文件>` 过校验）放进
  `C:\Users\<你>\.dsh\profile-data\desktop\dsh-trpg-table\content\packs\`
  → 重启 DSH（或由房主本机调 `content.reload` RPC，需 host token）→ 大厅「内容包 / 模组」里就能选到。坏包会被跳过并在 DSH 日志留 warning，不拖垮房间服务；同名内置包优先；
- **降级续团**：房间卡红字「内容包缺失或已变更」= 该房间引用的包在本机找不到，或包的版本/内容指纹变了。房间照常恢复、GM 回退内置内容继续带团；把对应 `.trpgpack` 放回上面目录并重扫/重启后，告警消失、恢复原内容；
- **改内置内容**：编辑 `packages/content/` 的源码 JSON 与 `packages/content/src/packs/core-guimuya.ts`，重新 build 后重启 DSH（内置包随插件编译，改动要重装插件）；自制内容建议一律走 `.trpgpack` + 数据目录，不动源码；
- **自制模组注意**：schema v1 字段名已统一（`cardId` / `sceneId` / `loreIds` 等，见 `docs/DESIGN.md` §6、`docs/CONTENT-MODEL.md` §2）；`scene.entry` 是开场旁白、`checks` 的 skill 用英文 id（如 `perception`）、`encounters.monsters.monsterId` 必须是 `MONSTERS` 里的 id、`scene.loreIds` 必须命中世界书 `loreId`——不放心就先跑一遍 CLI `validate`；
- **M8.2 限制**：大厅只做选择与展示；数据目录包需手工放置后重启 DSH（或由本机调 `content.reload` 重扫），
  或改用 §6.1 工坊「分享」tab 导入（导入即写入数据目录，可直接在大厅选到）；大厅目录不可用时只显示「目录不可用」并用内置包建房。

### 6.1 内容工坊（host 本机，M9.6a/M9.6b）

右栏「跑团桌」tab 的 host 专属「内容工坊」入口 → 主区域工坊页（左栏内容包列表 + 右侧 8 个 tab）：

- **只读查看**：概览（包/模组信息）、角色卡、世界书、模组（列表 + 分页折叠）；
- **编辑（M9.6b）**：角色卡/世界书/模组/规则表单可改并保存回 `.trpgpack`（校验不过不给存）；规则 tab 含
  规则校验与**规则测试台**（临时运行时跑样本检定，不建房间、不写文件）；
- **图标**：本地导入 / AI SVG / AI 生图三条路径，候选预览确认后才落盘（批量单次 ≤6）；资产写入 `assets/manifest.json`；
- **地图**：AI 生成战斗/世界结构（校验器硬闸，失败自动程序化兜底）→ 预览 → 写入规则包；底图与 `calibration` 对齐；
- **分享**：导出下载 `.trpgpack`、导入（冲突策略 reject/overwrite/rename）、内置包「复制为可编辑副本」。

注意：写操作与生图**仅本机 loopback + host token**（玩家不能用）；内置包 `core-guimuya` 只读，先复制副本再改；
编辑产物写回数据目录包（或副本），不影响正在进行的房间（房间按内容引用降级/重扫恢复，见 §5/§6）。

## 7. 疑难

| 现象 | 处理 |
|---|---|
| 玩家连不上 | 防火墙；确认同一网段；确认房间服务健康：浏览器打开 `http://<你的IP>:45871/trpg/health` |
| 绑定报「这个会话当前没有活动的 AI」 | 会话没有在 DSH 里打开（不是 live）；先打开该会话再点「绑定当前会话」 |
| DSH 停在「新会话」空态页，找不到「🎲 跑团桌」 | 看该页**左上角**：点入口会先请 DSH 新建一个会话再打开右侧栏；若仍提示「先在左侧「新会话」建一个会话」，通常是当前没有工作区，先在左侧新建会话 |
| 「AI GM 启动失败」 | 你的 DSH 模型配置不可用；检查设置→模型；房间仍可用真人 GM 模式玩 |
| 右栏红字「无法恢复房间：令牌无效或已失效」 | 本地记着一个已结束/失效的房间；重新加入房间即可（当前版本不会静默清理旧 token，属已知限制） |
| AI 不开口 | 看右栏卡片的牌桌会话与绑定状态；确认会话已打开；在会话里再发一次行动；确认插件 Host 已加载（DSH 重启过） |
| 大厅「内容包 / 模组」显示「目录不可用」 | 内容目录没读到（房主服务未就绪/版本不一致）；建房会静默用内置包、不影响开局。确认 `http://<你的IP>:45871/trpg/health` 正常后重进 tab 再看 |
| 房间卡红字「⚠ 内容包缺失或已变更」 | 该房间引用的包不在本机数据目录，或包的版本/内容指纹变了：把对应 `.trpgpack` 放回 §6 的目录，重启 DSH（或 `content.reload` 重扫）后恢复；期间 GM 回退内置内容继续带团 |
| 大厅看不到自制包 | 确认扩展名是 `.trpgpack`；用 §6.1 工坊「分享」tab 导入，或把文件放进 §6 的数据目录后重启 DSH；也可先跑 `node scripts/content-pack.mjs validate <文件>` 确认校验通过 |
| 端口冲突 | 关掉占用 45871 的程序，或给插件改端口（plugin config `port`） |

## 8. 已知限制（M6 + M8.2 + M9.6，本机实机验收通过 2026-11-17）

- **重载后旧 token 残留**：刷新/重载 DSH 后，若 localStorage 里残留旧房 token，右栏会红字提示「无法恢复房间：令牌无效或已失效」；重进 tab 或重新加入即可。应改为静默清理（尚未做）。
- **重开 tab**：页签已打开时再点对话头部「🎲 跑团桌」或空态页左上入口会重开页签（短暂空白 + 右栏宽度回默认），不会产生重复页签。
- **玩家退出不关房**：玩家点「退出房间」只离席，房间与牌桌绑定仍由你保留；只有你点「结束房间」才关房并解绑。
- **极窄栏宽**：≈300 CSS px 且多页签时页签标题会被截断（卡片本身正常）。
- **远端玩家行动入口**：玩家侧镜像（M7）只读；玩家在自己 DSH 里写行动 → 转发到牌桌会话的入口尚未接上。当前由你在牌桌会话里代录（或回归脚本调用 `room.say`）。
- **镜像与工具权限**：玩家镜像不投递 GM 秘密工具与暗骰；镜像依赖玩家本机 Web/桌面宿主与同源接口，升级插件后需重载。
- **内容包管理（M8.2/M9.6）**：工坊已支持导入/导出与编辑；但工坊写操作仅本机 loopback + host token，内置包只读；图标清单预览依赖 `pack.export` 浏览器内解包（大包首次稍慢），批量生成单次 ≤6；生成历史/差异视图未实现。
- **地图生成风格固定**：战棋 `topdown-2d`/`pixel-topdown`、世界图 `2d-illustration`；无 AI 时走程序化兜底（可导出可玩但构图简单）。
- **内容目录失败静默降级**：大厅只显示「目录不可用」，不展示具体原因（看 DSH 日志里的 content pack warning）。
