# 局域网验收清单（M5）

> 目标：主理人 + 1–3 位朋友在真实局域网跑完一局「鬼木崖·异光」。
> 本清单同时用于回归测试；每项通过打勾。

## 0. 准备

- [ ] 房主与所有玩家安装同一版本 `dsh-trpg-table`（本地 tgz 或目录安装），并**重启过 DSH**
- [ ] 房主确认 DSH 模型可用（设置 → 模型；AI GM 需要）
- [ ] 房主查到局域网 IP（`ipconfig`），确认与玩家同网段
- [ ] Windows 防火墙放行 TCP 45871（或首次弹窗时允许专用网络）
- [ ] 玩家端无需模型配置（顺带验证：`玩家端不配模型能否正常使用`）

## 1. 网络与房间

- [ ] 房主打开「🎲 跑团桌」→ 创建 AI GM 房间 → 得到邀请码
- [ ] 房主浏览器访问 `http://127.0.0.1:45871/trpg/health` 返回 `ok:true`
- [ ] 玩家浏览器访问 `http://<房主IP>:45871/trpg/health` 也能返回 `ok:true`
- [ ] 玩家用地址 + 邀请码加入成功
- [ ] 错误邀请码被拒绝；锁房后新玩家无法加入；解锁后恢复

## 2. AI GM 带团

- [ ] 建房后 30 秒内 AI 发出开场叙事（场景一）
- [ ] 某玩家提交行动 → 只有该玩家的角色被当作行动者（旁白不串到别人身上）
- [ ] AI 需要判定时调用工具：叙事流出现骰子卡（d20 与 DC/成败）
- [ ] 私骰：只有掷骰者与 GM 能看到结果
- [ ] 悄悄话：其他玩家收不到
- [ ] AI 没有替玩家写行动/台词；没有自己编伤害数字

## 3. 战斗

- [ ] 进入遭遇后出现 ⚔ 战斗面板（先攻顺序、第几轮、轮到谁、HP）
- [ ] 非当前行动者的攻击被拒绝（叙事提示“还没轮到你”/AI 不结算）
- [ ] 怪物 HP 归零后显示阵亡；战斗结束后面板不再推进

## 4. 真人 GM 干预

- [ ] GM 控制台：发送旁白，全桌可见
- [ ] GM 私发：只有目标玩家看到
- [ ] 推进场景：全桌看到「📍场景推进」，房间栏场景更新
- [ ] 发奖励：只有目标玩家看到奖励卡

## 5. 稳定性

- [ ] 玩家断网/刷新页面 → 自动重连并补发漏掉的事件（叙事不断档）
- [ ] 房主踢人 → 被踢玩家 token 失效，重新加入需要邀请码
- [ ] 房主 DSH 重启 → 房间从存档恢复，玩家重连可续团（事件序号连续）
- [ ] 手机/平板浏览器（dsh-pocket 场景）能加入并完成一次行动（可选）

## 6. 记录

- 完成一局后记录：
  - 一局时长、参战人数、模式（AI/真人）
  - 遇到的 bug（截图 + 复现步骤 + 事件序号）
  - 玩家反馈（节奏、信息量、AI 叙事质量）
- 结果贴到 GitHub Issues 或直接发给主理人，作为 M5 验收证据。
