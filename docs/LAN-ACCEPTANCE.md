# 局域网验收清单（M5 / UI v3）

> 目标：主理人 + 1–3 位朋友在真实局域网跑完一局「鬼木崖·异光」。
> 本清单同时用于回归测试；每项通过打勾。
> **状态（2026-11-16）**：本机单机链路已按 v3 实机验收通过（主区域=DSH 原生对话、头部入口打开右侧栏「跑团桌」页签、320/360px 栏宽布局、建房自动绑定会话、结束房间=关房解绑）；**局域网双机（host + 另 1–3 台真机）待执行**。
> **操作路径（v3 对话原生）**：房主开团 = 打开要当牌桌的 DSH 会话 → 对话头部「🎲 跑团桌」→ 右侧栏「跑团桌」tab「开团 · 我是房主」→ 创建房间（自动绑定当前会话）；玩家加入 = 同一头部入口 → tab「加入朋友的团」→ 填房主地址 + 邀请码 + 玩家名 → 加入 → 落座；房主结束房间 = 关房并解绑牌桌会话（玩家「退出房间」只离席、不关房）。

## 0. 准备

- [ ] 房主与所有玩家安装同一版本 `dsh-trpg-table`（本地 tgz 或目录安装），并**重启过 DSH**
- [ ] 房主确认 DSH 模型可用（设置 → 模型；AI GM 需要）
- [ ] 房主查到局域网 IP（`ipconfig`），确认与玩家同网段
- [ ] Windows 防火墙放行 TCP 45871（或首次弹窗时允许专用网络）
- [ ] 玩家端无需模型配置（顺带验证：玩家端不配模型能否正常使用）

## 1. 网络与房间

- [ ] 房主打开要当牌桌的 DSH 会话（只有被 DSH 页面驱动/live 的会话能让 AI 回话）
- [ ] 点对话头部「🎲 跑团桌」→ 右侧栏出现「跑团桌」页签（与其它页签并列、无重复页签）
- [ ] tab 大厅「开团 · 我是房主」：填团名、选 AI / 真人 GM →「创建房间」→ 得到 6 位邀请码（建房时把当前会话自动绑定为牌桌）
- [ ] 房主浏览器访问 `http://127.0.0.1:45871/trpg/health` 返回 `ok:true`
- [ ] 玩家浏览器访问 `http://<房主IP>:45871/trpg/health` 也能返回 `ok:true`
- [ ] 玩家点同一头部入口 → tab「加入朋友的团」：填房主地址 + 邀请码 + 玩家名 → 加入成功
- [ ] 玩家在 tab「落座 · 我的角色卡」选卡落座；房主「玩家席」看到该玩家与角色名
- [ ] 错误邀请码被拒绝；锁房后新玩家无法加入；解锁后恢复
- [ ] 房主点「结束房间」→ 关房并解绑：tab 回大厅、`room.list` 立即为空；刷新后不残留该房间

## 2. AI GM 带团（对话原生）

> 前置：房主已按第 1 节建房并绑定成功（房间卡片显示「已绑定本会话」）。
> **注意**：v3 删除了插件输入框，远端玩家的行动 UI 入口随 M7 玩家镜像开放。当前版本本节「行动注入」项由**房主在牌桌会话里以 `【角色名】…` 发言**或回归脚本 `room.say` 触发；M7 上线后改为玩家原生入口复验。

- [ ] 房主在牌桌会话里发一句开场（如「开始」）→ AI GM 在会话内原生回复，叙事进入第一幕「青石镇·悬赏」
- [ ] 行动注入：`room.say`（`【角色名】…`）以用户消息进入牌桌会话；只有该玩家的角色被当作行动者，旁白不串到别人
- [ ] AI 需要判定时调用 `trpg_roll_check` 等工具：会话里出现 DSH 原生工具卡（骰面 / DC / 成败），叙事与工具结论一致
- [ ] 私骰：只有掷骰者与 GM 能看到结果；悄悄话只到目标玩家
- [ ] AI 没有替玩家写行动/台词；没有自己编伤害数字（数字全部来自工具结果）
- [ ] 房主「结束房间」后再试：牌桌会话里不再出现 GM 系统提示与 `trpg_*` 工具（解绑生效）

## 3. 战斗

> v3 不再有「⚔ 战斗面板」；战斗由 AI 的 `trpg_*` 战斗工具推进，先攻/轮次/HP 以会话内原生工具卡呈现（`trpg_start_combat` / `trpg_combat_status` / `trpg_attack` / `trpg_next_turn`），右栏「掷骰」记录可对照。

- [ ] 进入遭遇后 AI 调用 `trpg_start_combat`：会话出现先攻顺序（第几轮、轮到谁、双方 HP）的工具卡
- [ ] 非当前行动者的攻击被引擎拒绝（工具返回「还没轮到你」之类，AI 不结算）
- [ ] 怪物 HP 归零后显示阵亡；`trpg_combat_status` 显示战斗结束，不再推进
- [ ] 战斗期间主区域始终是 DSH 原生对话（插件没有接管叙事区或输入框）

## 4. 真人 GM 干预

- [ ] GM 控制台（房主右栏 tab 房间卡片内）：发送旁白，全桌可见
- [ ] GM 私发：只有目标玩家看到
- [ ] 推进场景：全桌看到「📍场景推进」，房间栏场景更新
- [ ] 发奖励：只有目标玩家看到奖励卡
- [ ] 房间卡片「结束房间」= 关房并解绑牌桌会话（GM 提示与 `trpg_*` 工具撤销）；玩家「退出房间」只离席

## 5. 稳定性

- [ ] 玩家断网/刷新页面 → tab 自动重连并补发漏掉的事件（叙事不断档）
- [ ] 房主踢人 → 被踢玩家 token 失效，重新加入需要邀请码
- [ ] 房主 DSH 重启 → 房间从存档恢复，玩家重连可续团（事件序号连续）；牌桌会话需重新打开才能继续让 AI 回话
- [ ] 已知限制观察项（记录即可，不算失败）：重载后旧房 token 残留会红字提示「无法恢复房间：令牌无效或已失效」（待静默清理）；页签已打开时再点头部入口会重开页签（不产生重复页签）；≈300px 极窄栏宽 + 多页签时页签标题截断
- [ ] 手机/平板浏览器（dsh-pocket 场景）能加入、落座并在右栏掷骰（可选）
