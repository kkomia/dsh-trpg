# 玩家手册（跑团桌 · TRPG Table）

> 你只需要 DSH Desktop + 本插件。AI 在房主机器上跑，**玩家端不需要配置模型**。

## 1. 安装

1. 拿到房主发来的 `dsh-trpg-table-<版本>.tgz`；
2. DSH → **插件 → 添加插件** → 选择该文件 → 启用；
3. 重启 DSH（插件 Host 代码需要重启才生效）。

> 如果插件页没有「添加插件」入口，让房主把你的 DSH 升级到同版本，或参考仓库 README 的本地目录安装方式。

## 2. 加入房间

1. 问房主要两样东西：**房主电脑的局域网地址**（如 `http://192.168.1.10:45871`）和 **6 位邀请码**；
2. 在 DSH 任意会话输入框下方点「🎲 跑团桌」→ 填地址与邀请码 → 填你的玩家名 → **加入房间**；
3. 落座：在「玩家席」里选一张预制角色卡（阿青/白露/玄真/苏九）→ **落座**。想用自己的角色卡时，后续版本支持上传 JSON。

## 3. 桌上怎么玩

### 我的角色卡（本地卡库）

- **用预制卡**：玩家席下方选预制卡 → 落座；想长期养这张卡，点「存预制为本地卡」。
- **用自己导入的卡**：点「导入卡 JSON」选择角色卡文件 → 出现在「我的角色卡」下拉框 → 选中 → 落座。
- **导出/备份**：选中本地卡 → 「导出卡」下载 JSON，可换机器/角色卡库继续用。
- **散团成长**：收到 GM 奖励后，选本地卡 → 「合并成长到卡」把奖励物品叠进背包；XP 记在「我的成长」里。

| 操作 | 位置 | 说明 |
|---|---|---|
| **RP / 行动** | 右下「我的行动 / RP」输入框 | 用自然语言写你想做什么，例如「我推开门，先看门缝里的光」。服务端会把行动绑定到你的角色，AI/GM 只回应你这次的行动 |
| **悄悄话给 GM** | 同上，勾选「悄悄话给 GM」 | 只有你和 GM 能看到；其他玩家收不到 |
| **掷骰** | 右下「掷骰」 | 表达式如 `d20`、`2d6+3`；勾「私骰」则只有你 + GM 看到结果。骰子由房主服务端掷，可复现 |
| **看叙事** | 中间「叙事流」 | AI/GM 旁白、检定结果、战斗面板、场景推进、奖励都会出现在这里 |
| **战斗** | 叙事流中的 ⚔ 卡片 | 显示第几轮、轮到谁、双方 HP；轮到你时再写行动 |

## 4. 断线与重连

- 网络闪断时面板会自动重连，并从你上次看到的位置补发事件（不会丢剧情）；
- 如果显示「连接已断开」：刷新页面，或在面板里重新「检查」房主地址；
- 被房主踢出后，需要重新用邀请码加入（如果房间没锁）。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 打不开面板 / 没有「🎲 跑团桌」 | 插件未启用或 DSH 未重启；确认插件页里本插件为启用状态 |
| 加入时报「邀请码不正确」 | 确认 6 位邀请码、区分大小写无空格；问房主要最新邀请码 |
| 加入时报「房间已锁定」 | 房主锁房了，等房主解锁 |
| 「连不上房主」 | 确认你与房主在同一局域网；房主电脑防火墙放行 45871 端口；房主已点开过「跑团桌」面板 |
| 掷骰没反应 | 房主服务是否在线；刷新重试；私骰只有你和 GM 能看到，别问别人“你看到了吗” |
| 消息发出去没回应 | AI GM 在思考（通常几秒）；若出现“AI GM 这回合没接上”，再发一次即可 |

## 6. 礼仪（很重要）

- AI GM 只回应**本次行动者**；轮桌外请用 RP 交流，不要抢结算；
- 不要替别人的角色写行动或台词；
- 剧透秘密（GM 私发给你的信息）请留在桌上。
