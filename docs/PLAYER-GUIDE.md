# 玩家手册（跑团桌 · TRPG Table）

> 你只需要 DSH Desktop + 本插件。AI 在房主机器上跑，**玩家端不需要配置模型**。

> **UI v3（2026-11-16）**：跑团桌改为「对话原生」——入口在对话头部「🎲 跑团桌」按钮 / 右侧栏「跑团桌」tab（常驻卡片），不再有自绘聊天页与插件输入框；DSH 停在「新会话」空态页时，左上角也有「🎲 跑团桌」入口（点它会先准备一个会话再打开右侧栏）。**本机单机链路已实机验收通过（2026-11-16）**；**玩家侧原生会话镜像（M7）已开放（只读）**，行动转发的玩家端入口尚未接上（行动仍由房主代录），见 §3.1。

> **内容包（M8.2）**：内容包/模组由房主建房时选定（默认内置包「鬼木崖·异光」），玩家不需要选；进房后房间卡会显示当前内容包、模组与版本，缺包时房主侧会降级回退内置内容。

## 1. 安装

1. 拿到房主发来的 `dsh-trpg-table-<版本>.tgz`；
2. DSH → **插件 → 添加插件** → 选择该文件 → 启用；
3. 重启 DSH（插件 Host 代码需要重启才生效）。

> 如果插件页没有「添加插件」入口，让房主把你的 DSH 升级到同版本，或参考仓库 README 的本地目录安装方式。

## 2. 加入房间

1. 问房主要两样东西：**房主电脑的局域网地址**（如 `http://192.168.1.10:45871`）和 **6 位邀请码**；
2. 点「🎲 跑团桌」：正常对话页在对话头部；如果 DSH 停在「新会话」空态页（没有对话头部），点该页**左上角**的「🎲 跑团桌」——它会先准备一个会话再打开右侧栏 → 填房主地址、邀请码、玩家名 → **加入房间**；
3. 落座：在 tab 的「落座 · 我的角色卡」里选本地卡或预制卡（阿青/白露/玄真/苏九）→ **落座**；「导入卡 JSON」可上传自己的角色卡。
4. 进房后房间卡会显示房主所选的内容包 / 模组 / 版本；若看到红字「⚠ 内容包缺失或已变更，GM 回退到内置模组」，说明房主本机暂时缺这个包，GM 会先用内置内容带团——你不用处理，提醒房主按 GM 手册 §6 补包即可。

## 3. 桌上怎么玩

### 我的角色卡（本地卡库）

- **用预制卡**：右栏 tab 里选预制卡 → 落座；想长期养这张卡，点「存预制为本地卡」。
- **用自己导入的卡**：点「导入卡 JSON」选择角色卡文件 → 出现在本地卡下拉框 → 选中 → 落座。
- **导出/备份**：选中本地卡 → 「导出卡」下载 JSON，可换机器/角色卡库继续用。
- **散团成长**：收到 GM 奖励后，选本地卡 → 「合并成长到卡」把奖励物品叠进背包；XP 记在「我的成长」里。

| 操作 | 位置 | 说明 |
|---|---|---|
| **落座 / 角色卡** | 右栏 tab「落座 · 我的角色卡」 | 选本地卡或预制卡落座；导入/导出/合并成长也在这里 |
| **掷骰** | 右栏 tab「掷骰」 | 表达式如 `d20`、`2d6+3`；勾「私骰」则只有你 + GM 看到结果。骰子由房主服务端掷，可复现 |
| **队伍 / 在线** | 右栏 tab「玩家席」 | 谁在线、谁落座、角色名；房主可移除玩家 |
| **内容包 / 模组** | 右栏 tab 房间卡片 | 由房主建房时选择，玩家无需选；显示当前内容包、模组与版本；红色告警表示房主缺包、GM 暂用内置内容 |
| **看叙事 / AI 回复** | **本机镜像会话（原生对话）** | 加入后自动建「跑团桌：<房名>」本机镜像会话，用 DSH 原生界面看整局（原生气泡/工具卡/轮次）；只读、不跑模型、不消耗 key，见 §3.1 |
| **行动 / RP** | 告诉房主（房主在牌桌会话代录） | v3 起不再有插件输入框；行动转发到牌桌会话的玩家端入口尚未接上，**不要在镜像会话里写行动**（不会进房间，玩家端无 key 还会报错） |
| **悄悄话给 GM** | — | v3 暂未提供悄悄话开关；私密行动入口随后续版本补 |

### 3.1 玩家侧对话镜像（M7，只读）

- 你加入房间后，插件会在你的 DSH 里**自动创建一个本机镜像会话**（标题「跑团桌：<房名>」），并持续把这一局的
  原生事件（房主/AI 的叙事气泡、工具卡、轮次）同步进去；你不需要打开模型、也不需要 API key。
- 入口：右栏「跑团桌」tab 里的「对话镜像」卡——显示「已连接，已同步 N 条」；点「打开镜像会话」即可切到该会话；
  也可在 DSH 会话列表里找「跑团桌：<房名>」。
- 权限：你只看到自己可见的内容（公开叙事 + 发给你的私密），GM 的秘密工具与暗骰不会出现在镜像里。
- **只读**：镜像会话里发言不会转发进房间；行动请口头告诉房主，由房主在牌桌会话里代录。

## 4. 断线与重连

- 网络闪断时右栏 tab 会自动重连，并从你上次看到的位置补发事件（不会丢剧情）；
- 如果显示「连接已断开」：刷新页面，或在 tab 里重新加入；
- 被房主踢出后，需要重新用邀请码加入（如果房间没锁）。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 找不到「🎲 跑团桌」/ 右侧栏 tab | 插件未启用或 DSH 未重启；确认插件页里本插件为启用状态。正常对话页看对话头部，DSH「新会话」空态页看**左上角**（点它会先准备会话再打开右侧栏） |
| 加入时报「邀请码不正确」 | 确认 6 位邀请码、区分大小写无空格；问房主要最新邀请码 |
| 加入时报「房间已锁定」 | 房主锁房了，等房主解锁 |
| 「连不上房主」 | 确认你与房主在同一局域网；房主电脑防火墙放行 45871 端口；房主插件已启用且 DSH 重启过（Host 监听 0.0.0.0:45871） |
| 掷骰没反应 | 房主服务是否在线；刷新重试；私骰只有你和 GM 能看到，别问别人“你看到了吗” |
| AI 没回应 / 没有新叙事 | AI GM 在思考（通常几秒）；确认房主右栏卡片里的牌桌会话已绑定；你本机的「跑团桌：<房名>」镜像会话能看到房主的整局进度 |
| 右栏「对话镜像」显示不可用/失败 | 插件升级后需重启或重载 DSH；确认你用的是 Web/桌面宿主、已加入并落座；失败时仍可请房主复述或看右栏事件记录 |
| 房间卡红字「⚠ 内容包缺失或已变更」 | 房主本机缺该房间引用的内容包，GM 已回退内置内容继续带团；提醒房主按 GM 手册 §6 把 `.trpgpack` 放回数据目录并重扫/重启 DSH，玩家无需操作 |

## 6. 已知限制（M6 + M8.2 + M7，本机实机验收通过 2026-11-17）

- **重载后旧房 token 残留**：刷新/重载后右栏红字提示「无法恢复房间：令牌无效或已失效」，说明本地还记着一个已结束的房间；重新加入新房即可（当前版本不会静默清理，属已知限制）。
- **重开 tab**：页签已打开时再点对话头部「🎲 跑团桌」或空态页左上入口会重开页签（短暂空白、右栏宽度回默认），不会产生重复页签。
- **玩家退出不关房**：点「退出房间」只是你离席，房间与牌桌绑定仍由房主保留；重新加入即可继续；房主点「结束房间」才关房并解绑。
- **行动入口**：镜像只读；玩家在本机原生会话里写行动 → 转发到房间的能力尚未接上。当前请把行动告诉房主，由房主在牌桌会话里转述。
- **镜像依赖本机宿主**：镜像需要 Web/桌面宿主与插件 host 的同源接口；升级插件后要重启/重载。离线/精简宿主会显示「镜像不可用」。
- **内容包只读**：玩家不选包、也不下载包内容（只拿脱敏目录与房间引用），内容由房主本机决定；房主缺包时你看到的只是提示，不影响落座与游玩。

## 7. 礼仪（很重要）

- AI GM 只回应**本次行动者**；轮桌外请用 RP 交流，不要抢结算；
- 不要替别人的角色写行动或台词；
- 剧透秘密（GM 私发给你的信息）请留在桌上。
