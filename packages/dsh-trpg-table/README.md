# 跑团桌 · TRPG Table

局域网多人 AI 跑团桌，以 DSH 插件形态交付。房主建房、AI 当 KP/GM 负责裁定与叙事、玩家只负责 RP。

## 当前状态（M0 骨架）

- 房主端：运行局域网房间服务（默认 `0.0.0.0:45871`），提供 `GET /trpg/health`、`GET|POST /trpg/rooms`。
- 客户端：在对话输入框下方注册「跑团桌」入口，可探测房主、创建/列出房间。
- 规则引擎：`@dsh-trpg/engine` 已提供可复现骰子、检定；其余结算在 M1 落地。
- 协议：`@dsh-trpg/protocol` v1 信封与校验。

## 怎么用

1. 房主与玩家都安装本插件（`dsh plugin add` 本地目录或 tgz）。
2. 房主打开任意会话，输入框下方出现「🎲 跑团桌」，点开即启动房间服务。
3. 玩家在自己的 DSH 里打开同一入口，填写房主局域网地址（如 `http://192.168.1.10:45871`）后「检查」。

> 完整玩法、规则、模组与 AI GM 在 M1–M4 接入，见仓库 `docs/ROADMAP.md`。

## 已知限制（M0）

- 房间只在内存里，重启即失。
- 还没有 AI GM、角色卡、世界书、模组、战斗结算。
- Windows 首次监听端口时，防火墙可能弹窗，需允许专用网络访问。
