# 跑团桌 · TRPG Table

局域网多人 AI 跑团桌，以 DSH 插件形态交付。房主建房、AI 当 KP/GM 负责裁定与叙事、玩家只负责 RP。

## 当前状态（M2：房间服务 + 联机，AI 尚未接入）

- **房主端**：在本机启动局域网房间服务（默认 `0.0.0.0:45871`）。在「🎲 跑团桌」面板里创建房间，得到 6 位邀请码。
- **玩家端**：自己的 DSH 里打开同一面板，填房主局域网地址 + 邀请码加入；从四张预制角色卡里选一张落座。
- **桌上功能**：叙事流、玩家席在线状态、服务端掷骰（公共/私骰）、悄悄话给 GM、房主踢人/锁房、断线自动重连并补发事件。
- **规则引擎**：D&D 5e-lite（`@dsh-trpg/engine`）；AI GM 会在 M3 接入这套结算工具。

## 怎么用

1. 房主与玩家都安装本插件。
2. 房主打开任意会话，输入框下方出现「🎲 跑团桌」→ 创建房间（标题 + AI/GM 模式）。
3. 玩家打开同一入口，填房主地址（如 `http://192.168.1.10:45871`）与邀请码加入 → 落座。
4. 服务端没起来时，检查房主是否已打开过面板/DSH 是否重启过。

> 完整玩法、模组与 AI GM 在 M3–M4 接入，见仓库 `docs/ROADMAP.md`。

## 已知限制（M2）

- 房间只在内存里，DSH 重启即失（M4 存档）。
- 还没有 AI GM、战斗流程入口、存档与散团回传。
- 局域网明文 HTTP，仅限内网使用；公网/QQ 接入是 v2。
- Windows 首次监听端口时防火墙可能弹窗，需允许专用网络访问。
