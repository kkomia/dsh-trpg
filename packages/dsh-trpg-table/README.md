# 跑团桌 · TRPG Table

局域网多人 AI 跑团桌，以 DSH 插件形态交付。房主建房、AI 当 KP/GM 负责裁定与叙事、玩家只负责 RP。

M0–M9 主要能力完成：内容包 `.trpgpack`、规则运行时与沙箱、三屏/世界地图/战棋、资产与生图管线、内容工坊、

## 怎么用

1. 房主与玩家都安装本插件（同一版本 tgz：DSH 插件页「添加插件」选文件，或 `dsh plugin add <tgz 路径>`），安装后**重启 DSH**。
2. 房主先打开要作为牌桌的 DSH 会话（若停在「新会话」空态页，直接点该页左上角「🎲 跑团桌」，它会先准备一个会话）
   → 点「🎲 跑团桌」→ 右侧栏「跑团桌」tab →「开团 · 我是房主」（选内容包/模组与 AI/真人 GM）→ 创建房间，
   得到 6 位邀请码（建房会把当前会话自动绑定为牌桌）。
3. 玩家点同一入口，在右侧栏 tab 填房主局域网地址（如 `http://192.168.1.10:45871`）与邀请码加入 → 落座。
4. 玩家加入后右栏出现「对话镜像」卡，点开本机「跑团桌：<房名>」会话即可用 DSH 原生会话看整局（只读、不跑模型）。
5. 散团：房主点「结束房间」= 关房并解除牌桌会话绑定（GM 提示与 `trpg_*` 工具不再注入）；玩家「退出房间」只离席。

## 功能

- **对话原生牌桌**：房主当前会话即牌桌，AI GM 就是该会话的 Agent（插件注入 GM 系统提示与 `trpg_*` 工具），
  玩家行动以用户消息注入会话，GM 原生回复与工具卡由 DSH 渲染；插件只提供入口与右侧栏卡片。
- **规则运行时**：规则包（数据 + 受限公式 + 沙箱钩子）结算检定/战斗/移动/回合；数值只来自运行时。
- **内容包**：模组/世界书/角色卡统一 `.trpgpack`；建房选包，房间只存内容引用，缺包/变更时降级续团。
- **三屏与地图**：右栏人物/装备/背包，主区域人物详情/世界地图/战棋（底图、网格、token、回合与行动经济条）。
- **内容工坊（host）**：8 个 tab（概览/角色卡/世界书/模组/规则/图标/地图/分享），编辑内容包、生成图标与地图、
  导出/导入 `.trpgpack`、复制内置包为可编辑副本；地图生成走「AI 结构 → 校验器 → 程序化兜底」。
- **资产管线**：图标三路径（本地导入 / AI SVG / AI 生图），玩家立绘/头像/变体存本机 IndexedDB 并随落座上传。
- **玩家镜像**：host 按收件人投影会话事件，玩家本机原生会话重放（GM 秘密与暗骰不投递，不消耗 key）。
- **GM 工具**：检定/掷骰/私密/世界书检索/队伍/战斗/场景/奖励，真人 GM 控制台与存档续团。

## 已知限制

- 玩家镜像只读：行动仍由房主在牌桌会话代录；在镜像会话里直接发言不会进房间。
- AI GM 只能绑定当前在 DSH 里打开的会话（live）；插件新建/恢复的会话发模型请求会 transport 失败。
- 重载后 localStorage 残留旧房 token 会红字提示「无法恢复房间：令牌无效或已失效」（未静默清理）。
- 页签已打开时再点头部入口会重开页签（不产生重复页签）；≈300px 极窄 + 多页签时页签标题截断。
- 局域网明文 HTTP，仅限内网；公网/QQ 接入是 v2；Windows 首次监听端口需允许防火墙（TCP 45871）。
- 工坊写操作与生图仅 loopback + host token；内置包只读（先「复制为可编辑副本」）；zip 不支持 zip64；
  资产只收 PNG/SVG。
- 更完整清单见仓库 `docs/ACCEPTANCE.md` §3。
