# 跑团桌 · TRPG Table

局域网多人 AI 跑团桌，以 DSH 插件形态交付。房主建房、AI 当 KP/GM 负责裁定与叙事、玩家只负责 RP。

## 当前状态（M3：AI GM 编排完成，待实机联调）

- **房主端**：在本机启动局域网房间服务（默认 `0.0.0.0:45871`）。在「🎲 跑团桌」面板创建房间，得到 6 位邀请码；AI GM 模式建房后会自动创建 DSH Agent 会话并开场。
- **玩家端**：自己的 DSH 里打开同一面板，填房主局域网地址 + 邀请码加入；从四张预制角色卡里选一张落座。
- **桌上功能**：AI KP 叙事、玩家行动提交、服务端掷骰（含检定/私骰）、悄悄话给 GM、玩家席在线状态、房主踢人/锁房、断线自动重连并补发事件。
- **AI GM**：只有该 Agent 能看到 GM 工具（检定/掷骰/私密消息/世界书/队伍查询），叙事由 `assistant/message` 广播回房间；真人 GM 模式不会起 AI。
- **规则引擎**：D&D 5e-lite（`@dsh-trpg/engine`），AI 的数值全部来自引擎工具结果。

## 怎么用

1. 房主与玩家都安装本插件。
2. 房主打开任意会话，输入框下方出现「🎲 跑团桌」→ 创建房间（标题 + AI/GM 模式）。
3. 玩家打开同一入口，填房主地址（如 `http://192.168.1.10:45871`）与邀请码加入 → 落座。
4. 服务端没起来时，检查房主是否已打开过面板/DSH 是否重启过。

> 完整玩法、模组与 AI GM 在 M3–M4 接入，见仓库 `docs/ROADMAP.md`。

## 已知限制（M3）

- 运行中的 DSH 需要重启一次，才会加载 M3 版 Host（AI GM）代码。
- 战斗工具（先攻/攻击/怪物血量）尚未接入 AI；存档/散团回传在 M4。
- 房间只在内存里，DSH 重启即失（M4 存档）。
- 局域网明文 HTTP，仅限内网使用；公网/QQ 接入是 v2。
- Windows 首次监听端口时防火墙可能弹窗，需允许专用网络访问。
