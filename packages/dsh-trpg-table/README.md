# 跑团桌 · TRPG Table

局域网多人 AI 跑团桌，以 DSH 插件形态交付。房主建房、AI 当 KP/GM 负责裁定与叙事、玩家只负责 RP。

## 当前状态（M6：对话原生牌桌 · 本机实机验收通过 2026-11-16）

> 本机单机链路已验收（主区域=DSH 原生对话、头部入口打开右侧栏「跑团桌」页签、320/360px 栏宽布局正常、建房自动绑定会话、结束房间=关房解绑）；**局域网双机（host + 另 1–3 台真机）验收待执行**。

- **房主端**：打开一个 DSH 会话（它将成为牌桌），点对话头部「🎲 跑团桌」→ 右侧栏「跑团桌」tab「创建房间」，得到 6 位邀请码；建房会把当前会话绑定为牌桌（也可稍后点「绑定当前会话」），AI GM 就是这个会话的 Agent（会话需在 DSH 里打开，即 live，才能回话）。
- **空态页入口**：DSH「新会话」空态页没有对话头部时，点该页左上角「🎲 跑团桌」——会先请 DSH 新建一个会话，再打开右侧栏「跑团桌」tab。
- **玩家端**：点同一入口（正常对话页在对话头部），在右侧栏 tab 填房主局域网地址 + 邀请码加入 → 落座。
- **桌上功能**：AI GM 在牌桌会话里原生回复、`trpg_*` 工具卡由 DSH 原生渲染；右侧栏常驻卡片含房间状态、大厅、落座/角色卡、玩家席、掷骰、GM 控制台、成长/战报；断线自动重连并补发事件。
- **AI GM**：插件在牌桌会话的 Agent 上注册 GM 系统提示段与 `trpg_*` 工具；GM 的 assistant 文本回写房间事件；真人 GM 模式不会启动独立 AI 会话。
- **规则引擎**：D&D 5e-lite（`@dsh-trpg/engine`），AI 的数值全部来自引擎工具结果。

## 怎么用

1. 房主与玩家都安装本插件。
2. 房主先打开要作为牌桌的 DSH 会话（若停在「新会话」空态页，直接点该页左上角「🎲 跑团桌」，它会先准备一个会话）→ 点「🎲 跑团桌」→ 右侧栏「跑团桌」tab → 「创建房间」（标题 + AI/GM 模式）。
3. 玩家点同一入口，在右侧栏 tab 填房主地址（如 `http://192.168.1.10:45871`）与邀请码加入 → 落座。
4. 服务端没起来时，检查房主 DSH 是否重启过、是否打开过「跑团桌」tab。
5. 散团：房主点「结束房间」= 关房并解除牌桌会话绑定（GM 提示与 `trpg_*` 工具不再注入）；玩家点「退出房间」只离席，房间仍由房主保留。

> 完整玩法、模组与 AI GM 见仓库 `docs/ROADMAP.md`；玩家侧原生会话镜像在 M7。

## 已知限制（M6）

- 运行中的 DSH 需要重启一次，才会加载新版 Host 代码。
- AI GM 只能绑定当前在 DSH 里打开的会话（live）；插件新建/恢复的会话发模型请求会 transport 失败。
- 房间存档在 DSH profile-data 目录，重启后自动恢复房间；牌桌会话需重新打开。
- 重载后 localStorage 残留旧房 token 会红字提示「无法恢复房间：令牌无效或已失效」，应改为静默清理（尚未做）。
- 页签已打开时再点头部「🎲 跑团桌」会重开页签（短暂空白 + 右栏宽度回默认），不产生重复页签。
- 玩家「退出房间」只离席、不关房（设计如此）；房主「结束房间」才关房并解绑牌桌会话。
- 局域网明文 HTTP，仅限内网使用；公网/QQ 接入是 v2。
- Windows 首次监听端口时防火墙可能弹窗，需允许专用网络访问。
