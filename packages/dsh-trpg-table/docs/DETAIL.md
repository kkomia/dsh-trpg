# 跑团桌 · TRPG Table

## 它是什么

跑团桌是 DeepSeek Harness 的多人跑团插件：房主在自己电脑上建一间房，朋友用各自的 DSH 客户端加入；AI 担任 KP/GM，负责场景叙事、NPC 扮演、掷骰与全部数值结算；玩家只提交「我的角色要做什么」并 RP。

目标是把「C 位永远是玩家」还给跑团：AI 不当裁判、不抢戏、不替玩家做决定，只把规则与世界的反应呈现出来。

## 核心设计

- **确定性引擎**：掷骰、检定、伤害、先攻、状态由插件内的纯函数引擎结算；AI 通过工具拿结论写叙事，自己写出的数字不进入状态。
- **身份绑定**：玩家行动由服务端绑定到该玩家角色，AI 不推断「谁在行动」。
- **状态唯一写者**：角色状态只有引擎能改，事件日志可回放。
- **行动许可**：探索自由行动；战斗由服务器维护先攻轮，非当前行动者不会被误结算。
- **按人投影**：每个玩家只收到自己可见的公共叙事 + 私密层，私密信息在网络层就不会发给别人。
- **双 GM 模式**：AI GM（默认）与真人 GM（AI 当助手）共用同一套引擎与面板。

## 当前版本：M0 骨架

- 房主端房间服务（`0.0.0.0:45871`）：`/trpg/health`、`/trpg/rooms`。
- 客户端入口（对话输入框下方 dock）：探测房主、创建/列出房间。
- 规则引擎：可复现骰子与 d20 检定（`@dsh-trpg/engine`）。
- 房间协议 v1 信封与校验（`@dsh-trpg/protocol`）。

后续里程碑（M1 引擎与内容、M2 联机、M3 AI GM、M4 真人 GM、M5 局域网验收）见仓库根目录 `docs/ROADMAP.md`。

## 限制

- 房间只存在内存中，重启即失。
- 还没有 AI GM、角色卡、世界书、模组与战斗结算。
- Windows 首次监听端口时防火墙可能弹窗，需要允许专用网络访问。
